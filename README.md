# Reem — German FNOL Voice Agent

> Big Berlin Hack 2026 submission. A real-time German voice agent that handles inbound first-notice-of-loss (FNOL) calls for KFZ insurance — empathic, low-latency, and deployed on Cloudflare's edge.

📞 **Live demo number:** _see submission form_
🌍 **Production endpoint:** `https://reem.fnctn.io`

---

## What this is

Most voice-AI agents optimize for crispness and a "professional" tone. Real humans on a fender-bender call are warm, slightly disfluent, and ask about injuries *before* they ask for data. Reem is engineered for that.

Three things this project bets on:

1. **Empathy-first state machine + LLM-driven prosody.** Reem's first turn is always an injury check. Pause placement (`<break>` SSML tags) is generated by Gemini with full semantic context, then normalized at the TTS boundary so Gradium renders them as real silence.
2. **Code-mode for MCP.** Instead of one tool per backend (CRM lookup, fraud check, claim DB write, photo describe, Tavily research), Gemini gets a single `execute_typescript` tool. It writes TypeScript that calls typed globals; we run it in a Bun sandbox. ~97% smaller tool surface, parallel ops via `Promise.all`, and PII never enters the LLM's reasoning context.
3. **Edge-deployed on Cloudflare Containers.** The whole pipeline (FastAPI + Pipecat + Bun sandbox) runs as a Container with a Durable Object backing, EU-region, behind a custom domain. No tunnels, no flaky DNS — Twilio Media Streams hits the edge directly.

## Setup — local development

Requires: Python 3.11+, [uv](https://docs.astral.sh/uv/), [bun](https://bun.sh/), [ngrok](https://ngrok.com/) or any TLS tunnel.

```bash
# 1. Install Python + Bun deps
uv sync
bun install

# 2. Configure env
cp .env.example .env
# Fill in TWILIO_*, GRADIUM_API_KEY, GOOGLE_API_KEY, TAVILY_API_KEY, PUBLIC_HOST

# 3. Run the FastAPI relay (Pipecat agent + HUD + code-mode endpoints)
uv run python -m src.hud_relay

# 4. Expose it publicly so Twilio can reach it
ngrok http 8765   # use the wss URL as PUBLIC_HOST in .env

# 5. Point your Twilio number at it
uv run python scripts/point_twilio_to_cf.py
```

Now call your `TWILIO_PHONE_NUMBER` and Reem picks up.

## Setup — production (Cloudflare Containers)

Requires: a Cloudflare account, [wrangler](https://developers.cloudflare.com/workers/wrangler/install-and-update/), and Docker.

```bash
# 1. Authenticate
npx wrangler login

# 2. Set secrets (NEVER put these in wrangler.jsonc)
npx wrangler secret put GRADIUM_API_KEY
npx wrangler secret put GOOGLE_API_KEY
npx wrangler secret put TAVILY_API_KEY
npx wrangler secret put TWILIO_ACCOUNT_SID
npx wrangler secret put TWILIO_API_KEY_SID
npx wrangler secret put TWILIO_API_KEY_SECRET

# 3. Deploy
npx wrangler deploy
```

Cloudflare builds the Dockerfile, pushes the image to its registry, attaches the Container to a Durable Object class, and wires `reem.fnctn.io` to it via a custom domain route.

After deploy, point Twilio at the new endpoint:

```bash
PUBLIC_HOST=reem.fnctn.io uv run python scripts/point_twilio_to_cf.py
```

The script binds your Twilio number to a TwiML Application (`voice_application_sid`) instead of a `voice_url`, which survives the case where another developer on a shared Twilio account changes the URL.

## Voice tuning — the hard-won knobs

Every value in `snapshot.txt` is there because we A/B'd it on real calls. The big lessons:

- **Voice ID matters more than prompt.** Gradium's "Anna" (`D8iRHK1qJhqfE00v`) — German-native, balanced airy, deep empathy — beat the default English-trained "Emma" by a wide margin on German FNOL calls.
- **`padding_bonus = +0.4`** (positive = slower). Negative values, which we tried first, were the source of the "in a hurry" feel.
- **`<break>` tag normalization** is non-negotiable. Gemini sometimes emits `time='0.4s'` (single quotes) which Gradium reads aloud as text. We normalize every variant to `<break time="0.4s" />` (double quotes, space before slash) before TTS.
- **Greeting is LLM-generated**, not canned. A canned opener never matches the prosody variance of the rest of the call. We seed the context with a minimal `[Anruf gerade eingegangen]` primer; greeting-only rules live in the system prompt scoped to that primer.
- **Gemini 3.1 Flash Lite** beats 2.5 Flash on first-token latency (~720ms vs ~2000ms) for short conversational turns.

## Diagnostics

The deployed Container exposes a rolling event log at `/__diag`:

```bash
curl https://reem.fnctn.io/__diag | jq '.events[-20:]'
```

Cloudflare's `wrangler tail` does not work for Containers, so this in-process buffer is how we debug live calls.
